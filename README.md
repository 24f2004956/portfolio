# Portfolio Project

This repository contains a portfolio website and Python project with automated dependency management.

## Contact

Email: 24f2004956@ds.study.iitm.ac.in

## Features

- Portfolio website with product catalog
- GitHub Actions workflows for CI/CD
- Dependabot configuration for automated security updates
- Python dependencies managed via requirements.txt

## Dependencies

This project uses the following Python packages:
- FastAPI - Modern web framework
- Requests - HTTP library
- Pandas - Data analysis library
- NumPy - Numerical computing
- Pydantic - Data validation

## Automated Security Updates

Dependabot is configured to automatically check for dependency updates weekly and create pull requests with the prefix "deps".
